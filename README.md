# Agenda IPS SALUMED

Aplicación de agenda odontológica preparada para Cloudflare Pages y Supabase.

## Despliegue

En Cloudflare Pages, selecciona este repositorio, rama `main`, framework `None`, comando de compilación vacío y directorio de salida `/`.

## Seguridad

La aplicación requiere inicio de sesión y autorización de personal en Supabase. No guardar datos reales ni credenciales privadas en GitHub. Los recordatorios de WhatsApp no se envían hasta configurar el proveedor oficial en un backend protegido.
